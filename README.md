# Wota Grid Maker · 网站发布 / サイト公開

## 中文

这是我用来发布 Wota Grid Maker 的仓库。我把中文、日文和英文版的代码统一放在 [wota-grid-maker](https://github.com/kikisukii/wota-grid-maker)，通过这里的 GitHub Actions 发布网页，保留中日文原网址，并新增英文入口。

- [English](https://kikisukii.github.io/wota-grid-maker-en/)
- [中文版](https://kikisukii.github.io/wota-grid-maker/)
- [日本語版](https://kikisukii.github.io/wota-grid-maker-jp/)

我在主仓库维护代码，这里的发布流程约每 30 分钟检查一次 `main` 分支，有更新就发布。需要立即发布时，可以打开 [Actions](https://github.com/kikisukii/kikisukii.github.io/actions/workflows/publish.yml)，点击 **Run workflow**。

## English

I use this repository to publish Wota Grid Maker. I keep the Chinese, Japanese and English source together in [wota-grid-maker](https://github.com/kikisukii/wota-grid-maker), and publish the pages here through GitHub Actions.

- [English](https://kikisukii.github.io/wota-grid-maker-en/)
- [中文](https://kikisukii.github.io/wota-grid-maker/)
- [日本語](https://kikisukii.github.io/wota-grid-maker-jp/)

The workflow checks the source repository's main branch about every 30 minutes and publishes changes. For an immediate update, I can run it from [Actions](https://github.com/kikisukii/kikisukii.github.io/actions/workflows/publish.yml) using **Run workflow**.
