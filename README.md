# Wota Grid Maker · 网站发布 / サイト公開

## 中文

这是我用来发布 Wota Grid Maker 的仓库。我把中文版和日文版的代码统一放在 [wota-grid-maker](https://github.com/kikisukii/wota-grid-maker)，通过这里的 GitHub Actions 发布网页，继续使用原来的两个网址。

- [中文版](https://kikisukii.github.io/wota-grid-maker/)
- [日本語版](https://kikisukii.github.io/wota-grid-maker-jp/)

我在主仓库维护代码，这里的发布流程约每 30 分钟检查一次 `main` 分支，有更新就发布。需要立即发布时，可以打开 [Actions](https://github.com/kikisukii/kikisukii.github.io/actions/workflows/publish.yml)，点击 **Run workflow**。

## 日本語

Wota Grid Maker の公開に使っているリポジトリです。中国語版と日本語版のコードは [wota-grid-maker](https://github.com/kikisukii/wota-grid-maker) にまとめて管理し、ここの GitHub Actions から、これまでと同じ URL で公開しています。

- [日本語版](https://kikisukii.github.io/wota-grid-maker-jp/)
- [中文版](https://kikisukii.github.io/wota-grid-maker/)

コードの更新はメインリポジトリで行っています。公開用のワークフローが約 30 分ごとに `main` ブランチを確認し、更新があれば公開します。すぐに反映する場合は、[Actions](https://github.com/kikisukii/kikisukii.github.io/actions/workflows/publish.yml) の **Run workflow** から実行できます。
